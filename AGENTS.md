## Agent skills

### Issue tracker

Issues and PRDs for this repo live in GitHub Issues for `Cookiekira/DCTravelerCli`. See `docs/agents/issue-tracker.md`.

### Triage labels

This repo uses the default triage role labels (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`) plus GitHub category labels (`bug`, `enhancement`). See `docs/agents/triage-labels.md`.

### Domain docs

This repo is single-context: read root `CONTEXT.md` and relevant ADRs in `docs/adr/`. See `docs/agents/domain.md`.
